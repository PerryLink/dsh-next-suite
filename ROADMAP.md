# Roadmap

> Directional, not a promise. Community project, no SLA.

## dsh-next-suite 0.2.0

- capdiff: AST + dynamic import coverage; testatum: sigstore/provenance verification.
- supply-watch: registry feed + typosquat corpus; hmr-doctor: structured log adapters.
- migrate: official rule pack; testkit: async/fiber effects.
- xbrl: XBRL XML parser; atlas: target versions for all entries.

## Non-goals

- UI skins, generic memory, document pipelines, marketplaces.
- Claims of being official or audited.
- Publishing without provenance.
